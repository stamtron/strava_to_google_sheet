LIKELY BUGS
[x] 1. Strava webhook blocks the event loop — src/api/server.py (strava_webhook_event)
       async def calls blocking fetch_activity_detail + write_to_sheet inline, freezing
       dashboard/chat/Telegram worker during a sheet sync. Strava wants a reply in <2s
       and retries otherwise.
       Fix: return {"status": "ok"} immediately; do the work via BackgroundTasks /
       asyncio.to_thread.

[x] 2. Daily Telegram brief can be silently skipped — src/integrations/telegram.py
       (run_daily_dispatch_check)
       Fires only when current_hhmm == target_time exactly; a busy worker (/coach
       Gemini call, slow Garmin login) misses the minute -> no brief that day.
       _LAST_DISPATCHED_DATE is in-memory, lost on uvicorn reload.
       Fix: compare >= target_time, persist last-sent date in sync_state.

[x] 3. Background poller vs webhook conflict — src/api/server.py (lifespan telegram_worker)
       getUpdates returns 409 when a webhook is set, or when main.py --telegram-bot
       runs alongside the server. Errors logged at debug only, so invisible.
       Fix: poll only when no webhook configured; log at warning.

SECURITY
[x] 4. Telegram auth fails open — src/integrations/telegram.py (handle_telegram_command)

       Fix: reject when unset. Also validate X-Telegram-Bot-Api-Secret-Token header
       on /api/notifications/telegram/webhook (setWebhook secret_token).

       whole unauthenticated API.
